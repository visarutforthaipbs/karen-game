# Under Two Skies — game UI audit

Scope: game UI, Thai and English, keyboard/mouse and controller menu events.
The promotion and download websites are outside this pass. Existing campaign,
art direction and balance are preserved. The removed village panorama and
Visit the village action remain removed.

## Review method

Three native agents reviewed menus, gameplay surfaces and independent navigation.
The coordinator reviewed shared theme changes and integration. A separate agy
review supplied a complementary checklist; its suggestions were checked against
source and runtime evidence before acceptance.

The audit uses clear action hierarchy, legible information, predictable focus,
feedback and recoverable navigation as design criteria. [Microsoft's game UI
navigation guidelines](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/112)
and [Godot's focus documentation](https://docs.godotengine.org/en/stable/tutorials/ui/gui_navigation.html)
inform the navigation checks. This is not an accessibility certification.

## Accepted fixes

| Finding | Result |
| --- | --- |
| Tab escaped Settings and New Game confirmation into underlying controls | Shared `ModalFocusScope` disables background focus; nested scopes restore the opener. Release happens before close signals, including Settings → Guide replacement. |
| Repeating New Game while confirmation was open bypassed save consent | Repeated calls return; Escape/controller Back cancels; the saved campaign remains intact. |
| Controller A/B had no standard GUI Confirm/Back bindings | Standard GUI actions now receive A/B; Back closes one submenu at a time and resumes only from the pause menu itself. |
| Pause surrender/return-to-title actions acted immediately | Both require an isolated confirmation with Cancel initially focused. Surrender still runs the same scan and scoring logic after confirmation. |
| Preparation focus reached hidden ration, upgrade and mutual-aid choices | Scroll body follows actual keyboard/controller focus. |
| First-burn tips overlapped opaque voice captions | Tips wrap and settle their height, then reserve clearance above the actual caption rectangle. |
| Captions covered tool hints and vital labels at maximum scale | Gameplay reserves space above the actual visible bottom HUD controls; the default caption position returns outside gameplay. |
| Captions drew over higher-priority menus; refill marker drew over tips | Modal scopes temporarily suppress caption drawing without interrupting speech or losing its current transcript. Refill markers yield to instruction/caption/modal surfaces. |
| Dense warnings and long instruction could compete for the same space | Danger feedback and the spoken caption take priority; tutorial reading time counts only while the tip is visible. |
| Long English phase names hid their action behind an ellipsis | The phase label wraps while retaining the adjacent clock. |
| A previous warning timer hid a newer drone/ranger or wind warning | Each warning has a serial guard; warning lifetimes respect paused gameplay. |
| Cursor/player proximity made warning stack nearly transparent | Gameplay warning stack remains readable; passive HUD panels keep their existing proximity fade. |
| Game-over report promised a new campaign but led to the ending | The action now says View village outcome. |
| Rice copy said below 20%, but famine also occurs at exactly 20% | Thai/English copy states 20% or less; no rule changes. |
| Online score deletion stayed disabled after first opt-in and had no feedback | Availability updates immediately; pending/success/failure feedback is shown and retry becomes available. Local tests simulate responses; no public scores were deleted. |
| Settings sliders/text inputs lacked the shared focus treatment | Faceted slider thumbs and filled tracks highlight gold; text fields use the palette and gold focus outline. Wheel scrolling browses settings without changing a slider accidentally. |
| Deferred HUD callbacks survived scene removal | HUD-owned scheduling methods clean up connections automatically; detached callbacks are guarded and scene-cycle lifecycle checks verify removal. |

## Surface coverage

| Surface | Evidence checked |
| --- | --- |
| Title / saved-game confirmation | New/Continue hierarchy, existing-save preservation, full focus cycle, Back cancellation, scaled layout |
| How to play | Scroll reachability, fixed close action, nested return, language and scale |
| Settings | Language, audio/display/gameplay/privacy/tester sections, focus and scroll, opt-in/deletion feedback, sibling guide transition |
| Pause / surrender / return to title | Frozen game, one-level Back, safe default, explicit confirmation and exactly one scan |
| Preparation | Radio, rice, rations, briefing, workshop, mutual aid, pinned launch; no decorative preview; focused choices revealed |
| Gameplay HUD | Clock/phase/goals/wind/scrutiny/tools/crew/water/breath, transient warnings, minimal HUD, caption/tip clearance |
| Satellite report | Success/failure/famine/crackdown, dense GIS entries, scroll body, pinned action, actual destination |
| Harvest | Normal and famine, long next-year rules, focus isolation and return |
| Checkpoint | Existing localized narrative/skip path reviewed; scene remains skippable |
| Ending / summary | Both causes, captions, skip, local/online summary, editable untranslated name, fixed retry/title actions |
| Debug overlay | Existing tester-only visibility and localized readouts reviewed; no production feature added |

Layout target: 1280×720, Thai/English, default and maximum 1.3 UI scale.
Preparation also retains its existing narrower/shorter viewport checks. Captures
use staged state with isolated saves and settings; they are layout evidence,
not measurements from a human playtest.

## Verification and decision

**Manager decision: GO for local playtesting.** All confirmed blocking findings
were fixed and independently reviewed. Shared fonts, faceted panels, colour roles
and the existing game identity are retained.

| Check | Result |
| --- | --- |
| Real keyboard/controller navigation | 37 checks, zero failures |
| Menu behavior and layouts | 86 checks, zero failures; also passed native capture run |
| Localized menus/reports/endings | 167 checks, zero failures |
| Localized gameplay/preparation/harvest | 245 checks over 278 rendered Controls, zero failures |
| Gameplay overlays and feedback | 540 checks, zero failures, including all 30 spoken clips in both languages at both scales |
| Speech/subtitle runtime | 49 checks, zero failures |
| Integrated gameplay regression | 149 checks, zero failures |
| Catalog validation | 377 entries + 30 voice transcripts; no missing source translations |
| 120-frame smoke / source whitespace | Passed; no script or parse errors |

The three new UI behavior suites are included in CI, with log checks for script
errors in addition to exit codes. The integrated gameplay test deliberately reads
corrupted JSON fixtures. Some headless fixtures retain existing teardown ObjectDB
warnings; the ordinary 120-frame application smoke log is clean.

Evidence: `artifacts/ui_audit_20261003/manager_review.json` and adjacent logs.
Native menu captures are actual 1280×720 windows. Gameplay captures render the
actual staged controls at 985×554 logical size into 1280×720, matching the maximum
scale; runtime geometry tests separately apply real root content scaling.
