# 0. Executive Direction

The character pipeline is being revised around one principle:

> **Do not make generic “Karen-looking” game characters. Build fictional characters from documented contemporary Pgakenyaw people, communities, clothing, occupations, body language, and ecological practice in Northern Thailand — then translate those references into the game’s cute faceted low-poly chibi style.**

The characters remain fictional. Real people are used as **human/cultural references**, not copied one-to-one.

The design process is now:

```text
RESEARCH
→ REAL PEOPLE / COMMUNITY REFERENCES
→ CULTURAL + CLOTHING LOGIC
→ CHARACTER SILHOUETTE
→ CLEAN PRODUCTION A-POSE
→ TRELLIS CANDIDATES
→ 4-ANGLE + STYLE + CULTURAL REVIEW
→ CHARACTER-SPECIFIC RIG CALIBRATION
→ DEFORMATION REVIEW
→ GAMEPLAY ANIMATION / TOOL INTEGRATION
→ INSTALL
```

Two gates can never be waived:

1. **Faceted Low-Poly Style Gate**
2. **Pgakenyaw Cultural Authenticity Gate**

# 1. Core Art Direction

## 1.1 Aesthetic

**Cute Faceted Low-Poly Chibi**

- 2.5–3.0 heads tall
- strong readable silhouette
- visible flat polygon facets / unsmoothed normals
- broad painted color areas
- restrained stylized textures
- matte surfaces
- simplified but recognizable cultural details
- proportions designed for gameplay readability, not realism
- characters should feel like small painted diorama figures

## 1.2 The World Palette

### Daytime
- mountain emerald green
- bamboo straw yellow
- terracotta clay soil
- indigo textiles
- warm skin / wood / leather

### Evening
- ochre / sepia haze
- charcoal ash black
- glowing ruby / amber embers

### The surveillance-state visual layer
- cold white
- infrared false colors
- clinical drone light

**People, land, houses, farming, textiles and tools should feel warm.  
The surveillance layer is the intentional cold intrusion.**

## 1.3 Banned

- photorealistic skin
- realistic pores
- dense fabric microtexture
- noisy normal maps
- glossy realistic PBR
- generic “tribal” fantasy decoration
- ultra-fine woven patterns that disappear at gameplay distance
- smoothing that destroys faceting
- more polygons as a substitute for better design
- pan-Asian costume mixing without evidence

# 2. New Real-World Reference Policy

Real public figures may be used to establish:

- facial planes
- age
- complexion
- posture
- physical presence
- clothing logic
- headwear
- ways of carrying tools
- field movement
- community role
- work practices
- relationships with forest / farm / village

## 2.1 Do Not Make Exact Copies

Unless a future production decision explicitly says otherwise:

- do not reproduce a living person as an exact portrait;
- do not imply endorsement;
- do not put fictional actions or dialogue into the real person’s identity;
- do not copy a complete real outfit and biography into the fictional character.

The goal is:

> **recognizable contemporary Northern Pgakenyaw humanity — not celebrity cameos.**

## 2.2 Reference Atlas Rule

Each character should have separate references for:

| Reference | Purpose |
|---|---|
| Human | face, age, body, expression, posture |
| Clothing | garment structure, textile placement, headwear |
| Work | tools, carrying system, task |
| Movement | gait, climbing, crouching, working, resting |
| Community | environment, houses, farm, forest, social context |

# 3. Research Finding: Huai Hin Lad Nai Is Now a Major Reference Community

# 8.3 Clothing — White Dress Becomes the Core Mu-naw Identity

The user-provided clothing reference shows a young Pgakenyaw woman in a **white woven dress**.

This is now the preferred design direction for Mu-naw.

## Core garment

**White / warm ivory woven Karen dress**

Design principles:

- long, simple vertical garment silhouette;
- white / warm ivory as dominant field;
- dark or red woven accent bands only where supported by reference;
- broad geometric bands, not micro-pattern;
- textile character expressed through silhouette and color blocking;
- no synthetic-fantasy ornament;
- no unnecessary layered armor.

## Important cultural note

Do **not** automatically attach a marital-status meaning to the white dress in production documentation unless the specific Huai Hin Lad Nai / local usage has been independently verified.

For the game, the immediate canonical statement is:

> **Mu-naw wears a white Pgakenyaw woven dress based on the supplied real-world visual reference of a young Karen woman.**

# 8.7 Mu-naw Fire / Forest Gear

We still need a strong gameplay silhouette for ember suppression.

However, the gear should now be treated separately from cultural dress.

Preferred principle:

> **Traditional / community clothing + practical contemporary or locally plausible forest-protection equipment.**

This is stronger than turning the clothing itself into fantasy firefighting gear.

## Water-suppression equipment

The existing **15 L knapsack tank + hose + nozzle** remains a possible gameplay system, but its exact form must be researched.

Questions before final lock:

- Is brass correct?
- Is metal correct?
- Is plastic / steel more locally plausible?
- What backpack sprayers are actually used in Northern Thai community fire work?
- How is hose/nozzle carried?
- Would a modified agricultural sprayer be more authentic?
- Is the equipment supplied by community / government / locally adapted?

### Temporary production rule

If the existing tank is required for gameplay:

- keep the tank visually separate from the white dress;
- keep shoulder harness readable;
- do not let straps erase the garment silhouette;
- hose must not fuse with arm / thigh;
- nozzle must remain a separate rigid prop;
- the white dress must remain the first-read cultural identity.

# 10. Mandatory Cultural Authenticity Gate

Before any production model is approved, answer:

## Person

- Who are the real references?
- What exactly are we borrowing?
- What are we explicitly not copying?

## Locality

- Which community / district / province grounds the design?
- Are all clothing references from the same cultural context?
- Are we mixing sources from Chiang Mai, Chiang Rai, Lamphun, Mae Hong Son, etc. without justification?

## Clothing

- Is this daily wear?
- field wear?
- ceremonial?
- formal?
- historical?
- contemporary?

## Pattern

- Is it documented?
- Is it meaningful?
- Are we simplifying correctly?
- Are we inventing symbolism?

## Tools

- Is the tool actually used?
- Is the scale plausible?
- Is it carried this way?
- Is it traditional, commercial, improvised or fictional?

## Narrative

Does the asset reinforce that rotational farming is a managed agroecological system rather than careless slash-and-burn?

# 13. Generation Risk

TRELLIS candidate generation is expected to require iteration.

Known problems:

- damaged hands
- holes
- fused geometry
- broken textile bands
- wrong proportions
- weak likeness
- gear merged into torso
- hose fused to limbs
- photoreal texture drift

**Validation passing is not approval.**

Visual review can and should reject candidates.

---

# 14. Style Gate

Reject when:

- character looks photoreal
- texture has realistic skin detail
- cloth uses noisy weave microtexture
- surface is glossy
- shape language is too smooth
- faceting is weak
- textile pattern becomes visual noise
- character does not belong beside the existing terrain / props / cast

> The validator does not measure art style.

---

# 15. Rigging Gate

There is **no universal automatic rigging profile**.

Each mesh needs:

- calibrated landmarks
- reviewed weight regions
- rigid accessory review
- max-bend renders
- deformation review

A mesh hash is not calibration.

- two-hand tools

# 16. Animation / Gameplay Integration Gate

The project’s existing 7 integration risks still stand.

Before declaring any character gameplay-ready, verify:

1. target-facing is wired;
2. animation event drives tool effect timing;
3. tool use works while locomotion continues;
4. stride playback matches world velocity;
5. semantic companion actions / sockets exist;
6. task timing follows animation / action clock;
7. gameplay reach matches visible contact.

Required behavior review:

- Idle
- Walk
- Turn
- Stationary tool use
- Moving tool use
- Slope movement
- Smoke slowdown
- Task interruption
- Recovery
- End-of-day settle
